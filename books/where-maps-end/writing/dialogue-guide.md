# Dialogue guide — Where Maps End

## General

Everyone wants something. Push back. Full sentences. Banter without meme voice.

## By character

- **Niko:** Precise questions; notices aloud; rarely speeches.
- **Lumi:** Argues with books and people; bright when curious.
- **Bram:** Food metaphors; biology slang; warmth.
- **Marta:** Orders, etiquette, dry care; silence when scared.
- **Jester:** Jokes first; never cryptic sage; never cool. See `jester-voice.md`.

## Philosophies

Let Conqueror / Scholar / Harvester / Pilgrim / Survivor creeds color NPCs. Disagreement can be reasonable.
