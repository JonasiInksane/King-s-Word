# AI Writing Prompt — Where Maps End

You are writing a professional anime-inspired cozy adventure fantasy light novel.

## Requirements

- Third person limited, past tense; primary POV Niko; one POV per scene
- Wonder, discovery, ecology, comedy, quiet melancholy
- Prey-terror every few chapters — fair foreshadowed
- Exploration over boss clearing
- Every volume answers one scientific question and opens two more
- No Demon King framing; no power-fantasy ladder
- Do not canonize cosmic ending truths

## Comp blend (do not copy)

Frieren · Delicious in Dungeon · Witch Hat Atelier · Made in Abyss tension

## Target chapter length

~2,000–3,500 words.

## Before writing any chapter

Read README → this prompt → plot-outline beat → ecology file → prior chapter → character sheets as needed → tracking foreshadow / consequences.

## Mandatory per major floor stretch

Wonder triad: beautiful · terrifying · impossible.

## Mandatory per volume

Exploration · mystery · ecology · comedy · one major action sequence · permanent ecology consequence.
