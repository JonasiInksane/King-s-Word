# Character Roster Index

Scaffold for a long-series cast. **Names stay TBD until deliberately filled.**

Do not write full bios here. Each entry needs only:

| Field | Meaning |
|---|---|
| **Name** | Locked when introduced |
| **Philosophy** | One sentence — control / freedom / truth / order |
| **Ability** | Rei discipline (Shiki / Kotodama / Kage) + Resonance hook, or none |
| **Fool vector** | How they misread The Fool |
| **Status** | `empty` · `named` · `introduced` · `recurring` · `dead` · `offstage` |

**Main cast bios** live in individual files. This index tracks depth for 250–350 chapters.

**Canon anchors** ([`tracking/canon.md`](../../tracking/canon.md)):

- World: Akaritsu · Kingdom: Akatsuki · Fool: Harlequin Akihiko
- Emperor Seiryu · Princess Ayame · Inquisitor Kuro
- Magic: Rei (Shiki / Kotodama / Kage) · Axioms · Resonance

**Wave rule:** Never introduce a full set on-page until that institution matters. Fill slots as arcs need them.
